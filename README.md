# 💰 Personal Finance Tracker

> **A smart personal finance management application built with Flutter to help users track expenses, manage savings, set financial goals, and make better financial decisions.**

---

## 📌 Overview

**Personal Finance Tracker** is a Flutter-based mobile application designed to help users manage their personal finances from one centralized platform.

The application allows users to track their daily transactions, monitor spending patterns, manage savings, set financial goals, scan transactions, receive AI-powered financial assistance, and stay motivated through rewards and achievements.

The platform brings together essential personal finance tools in a single, intuitive application.

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

* Flutter SDK
* Dart SDK
* Android Studio or Xcode
* An Android emulator, iOS simulator, or physical device

---

### 1. Clone the Repository

```bash
git clone <repository-url>
cd personal_finance_tracker
```

---

### 2. Install Dependencies

```bash
flutter pub get
```

---

### 3. Run the Application

```bash
flutter run
```

---

### 4. Build the Application

For Android:

```bash
flutter build apk
```

For iOS:

```bash
flutter build ios
```
